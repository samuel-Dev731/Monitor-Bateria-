# Monitor de Bateria Pro

Aplicativo Android em Kotlin para acompanhar a bateria do dispositivo.

## Recursos
- Percentual e estado da bateria em tempo real.
- Temperatura, tensão e corrente quando o Android disponibilizar.
- Estimativas de saúde e capacidade, claramente identificadas como estimativas.
- Histórico local de eventos de carga e descarga durante a execução do app.
- Gráficos simples e alertas configuráveis.

## Build
O GitHub Actions compila o APK de depuração e publica o artefato `Monitor-Bateria-Pro-debug`.

## Observações
A disponibilidade de corrente, capacidade e saúde depende do fabricante, hardware e versão do Android. Este aplicativo não substitui medições de laboratório e não promete precisão quando o sistema não fornece os dados.
